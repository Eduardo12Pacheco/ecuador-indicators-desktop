# Ecuador Indicators

[![CI](https://github.com/Eduardo12Pacheco/ecuador-indicators-desktop/actions/workflows/ci.yml/badge.svg)](https://github.com/Eduardo12Pacheco/ecuador-indicators-desktop/actions/workflows/ci.yml)

A polished, offline-first desktop application for exploring, comparing and
exporting Ecuadorian economic and social indicators from a bundled World Bank
snapshot.

> Work in progress. The repository is being built task by task; the final
> README, screenshots and installers arrive with the release tasks.
